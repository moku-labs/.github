# .github

The organization profile of [moku-labs](https://github.com/moku-labs).

- `profile/README.md` is the page GitHub shows on the organization.
- `.github/workflows/fleet.yml` rewrites the table between its two markers every 15 minutes.

The workflow is a copy of `examples/org/fleet.yml` from [`@moku-labs/ci`](https://github.com/moku-labs/ci).
